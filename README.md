# explore.cincinnati — test site

Static preview of the explore.cincinnati website design (photographs, print shop, stories, private Studio).
Plain HTML/CSS/JS, no build step. Deployed on Vercel from this repo.

- `index.html` — Home
- `collection.html` — Prints (gallery walk) ⇄ Stories
- `print.html` — Print detail with size / paper / frame configurator
- `story.html` — A story (full Instagram caption)
- `studio.html` — Private admin & analytics mockup (sample data)
- `dc.js` — tiny template runtime; `site.css` — responsive tweaks
